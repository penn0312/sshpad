# 命令库 JSON

在扩展设置打开「导入命令库」，选择 UTF-8 JSON。可从 [示例](../examples/commands.example.json) 开始。任何工具均可生成这份 JSON。

| 字段 | 格式 |
| --- | --- |
| `version` | 固定为 `1` |
| `sourceId` | 命令库的稳定标识。`local` 保留给扩展手动创建的分组 |
| `groups` | 按显示顺序排列的数组，可为空 |
| `groups[].id` | 在该来源内唯一的分组标识 |
| `groups[].name` | 分组名称 |
| `groups[].commands` | 按显示顺序排列的非空命令数组 |
| `commands[].id` | 在该来源内唯一的命令标识 |
| `commands[].name` | 按钮名称，同组内唯一 |
| `commands[].command` | 单行文本，内容取决于发送模式。Shell 模式可填写 `pwd && whoami` |
| `commands[].mode` | 可选。`auto` 为默认模式，识别无引号的 `\n\p` 或 `\r\p`。`shell` 作为单行命令，`send-string` 按发送字符串解析 |
| `commands[].color` | 可选。支持 `default`、`blue`、`green`、`amber`、`purple` 和 `red` |

标识可以使用小写 ASCII 字母、数字、点、下划线和连字符。首字符需要是字母或数字，最长 80 个字符。名称上限为 1024 个 UTF-16 码元，命令正文上限为 65536 个 UTF-16 码元，导入文件上限为 8 MiB。命令正文须移除回车、换行、控制字符和凭据占位符。Shell 模式会自动追加回车。

在发送字符串模式中，`\n` 和 `\r` 提交当前行，`\p` 暂停一秒，`\\` 表示一个反斜杠。中间行以回车标记结束，末行会自动提交。暂停放在行之间或开头。一次最多提交 20 行，总暂停不超过 20 秒。JSON 中要转义这些反斜杠，例如 `"command": "git pull\\n\\pusername\\n"`。

更新文件时保持 `sourceId`、分组 ID 和命令 ID。稳定 ID 会保留站点的分组选择和本地命令修改。重新导入同一来源时，本地删除继续生效。已经在扩展内编辑过的命令即使从导入文件移除，也会保留到手动删除为止。设为「显示所有分组」的站点会自动显示新增组，选择了具体分组的站点可以手动勾选新组。

扩展内设置的颜色和分组名称在重新导入时保留。单独修改颜色后，命令正文和按钮名称仍可随来源更新。
