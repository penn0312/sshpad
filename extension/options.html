    分组重命名

    例如 git pull\n\pusername，提交命令后等一秒，再提交用户名。

    可用 pwd && whoami 在上一条成功后继续。像 sudo git pull 这样的交互命令只填写命令本身，等提示出现后在终端输入。

    \n 或 \r 表示回车，\p 暂停一秒，\\ 发送反斜杠。按固定时间发送。示例 git pull\n\pusername。
